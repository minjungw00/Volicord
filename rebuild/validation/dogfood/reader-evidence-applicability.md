The private reference copy is checked against its own manifest. Historical B/Click
still support presentation/source-link controls; excluding task-time claims does not
delete those positive cases. Original runtime body retention is not reauthorized by
reading an archived reference. All Product reads must recheck current association,
format, expiry, deletion and forgetting. Input/hash provenance alone cannot prove
semantic entailment, authentic host activity or a user judgment.

`explanation_evidence.reader_applicability` is consumed by the existing campaign
`prepare-explanations` and `inspect-explanations` workflows. It reports per-subject
record/article/code-read/comparison/named-command/retest/task-time/human applicability,
with input hashes and precise gaps. It performs no capture or provider dispatch.
Optional scoped read inputs require exact Project/Work/revision/Source/snapshot,
current copy format and read-time lifetime. Missing-before, missing-before-inspection,
expired retention and deleted body remain separate. Recommendation reading survives
unavailable Source support while absent user reason stays absent. An origin label or
self-reported authority never establishes genuine task-time authenticity. Eligibility
means an input may be assessed, never that the claim or AC passed.

Compact controlled trace: `work source observe` before → actual fixture edit → fresh
analysis → `observe --before-source` after → `run --label` → `source list/read` →
`work explain prepare/compose/record` → `status` excerpts. This supplies bounded
answers to “what bytes changed?” and “what did the named command actually observe?”
It supplies no cause, retry, exclusive attribution or user choice by itself. An
error-free/no-change/no-Decision task needs none of those fictional events.
