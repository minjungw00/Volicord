# `volicord.finalize_advice` reference

This document owns the public method that applies exact current advisor-owned
shaping decisions and establishes the current advice result and
checkpoint-backed close basis. It does not create or replace a checkpoint,
create a UserAction request, advance a Task phase, record a Run, issue a write
ticket, or write Product Repository files.

<a id="surface-stability"></a>
## Surface Stability

The method name, direct request and response schemas, exact decision
application semantics, and aggregate close-basis transaction are `stable`.

The request directly supplies the exact `shaping_checkpoint_id`, current
non-write `change_unit_id`, `scope_revision`, non-null `baseline_ref`, complete
`user_action_resolution_ids`, `result_summary`, supported `result_refs` and
`evidence_refs`, `residual_risks`, and `recovery_constraints`. There is no
outer operation union.

The Task must have `mode=advisor` and `work_phase=shaping`. The checkpoint must
be the exact current structurally ready checkpoint with no current gap. The
Change Unit, scope revision, and baseline must be exact and current. Every
advisor-owned gap must have exact current accepted User Channel authority;
every scope-owned gap must already be applied through
`volicord.update_scope`. The supplied resolution IDs are the unique complete
set for advisor-owned accepted gaps. Detached, rejected, deferred, expired,
stale, superseded, or inconsistent authority cannot finalize advice.

## Atomic behavior

One committed call creates one immutable `ShapingDecisionApplication` for each
newly applied advisor-owned accepted gap, marks only those source gaps applied,
preserves the checkpoint identity, records the advice result and supported
refs, records residual risks and recovery constraints, establishes the
checkpoint-backed `CurrentCloseBasis` with exact application lineage, appends
one method event, stores the replay result, and increments `state_version`
exactly once. Failure rolls back the whole aggregate. Exact replay returns the
original result; a conflicting replay has no effect.

This method is the sole advisor shaping decision application owner. Checkpoint
recording is not an application owner.

## Workflow recovery

Before finalization, the ready advisor state selects
`ready_to_finalize_advice`, `next_actor=agent`, and
`required_action=volicord.finalize_advice`. A successful call selects
`close_review`. Rejected, deferred, or expired authority selects
`decision_recovery_required` and recovery through
`volicord.record_shaping_checkpoint`; stale application authority selects
checkpoint replacement through that same method. Pending authority selects
`volicord.resolve_user_action`, and unapplied advisor scope authority selects
`volicord.update_scope`.
